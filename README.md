<h1>Projeto Integrador Interdisciplinar (PII)- Metrô de São Paulo</h1>

🇧🇷 - Este projeto consiste no desenvolvimento de uma solução digital multiplataforma para a gestão inteligente de estoques e instrumentos, realizado em parceria com o Metrô de São Paulo (Departamento de Restabelecimento de Sistemas).
<br>
O objetivo é substituir controles manuais descentralizados por um sistema integrado que garanta rastreabilidade, eficiência logística e segurança patrimonial para as 12 bases de manutenção.
󠁧󠁢󠁥󠁮

🇬🇧 - This project consists of developing a cross-platform digital solution for intelligent inventory and instrument management, carried out in partnership with Metrô de São Paulo (Systems Restoration Department). The objective is to replace decentralized manual controls with an integrated system that ensures traceability, logistical efficiency, and asset security for the 12 maintenance bases.


## MetrôSP

🇧🇷 - Esta solução foi projetada para atender a uma operação crítica 24/7, automatizando o controle de materiais e instrumentos técnicos. A ferramenta permite o monitoramento em tempo real de entradas, saídas e movimentações entre bases e veículos, além de gerenciar a calibração de ferramentas e emitir alertas de estoque mínimo. Com interfaces responsivas e dashboards analíticos, o sistema oferece aos técnicos e gestores uma visão consolidada do inventário, reduzindo extravios e otimizando o tempo de restabelecimento de falhas operacionais.

🇬🇧 - This solution was designed to support a critical 24/7 operation, automating the control of materials and technical instruments. The tool enables real-time monitoring of entries, exits, and movements between bases and vehicles, in addition to managing tool calibration and issuing minimum stock alerts. With responsive interfaces and analytic dashboards, the system offers technicians and managers a consolidated view of the inventory, reducing losses and optimizing the recovery time for operational failures.
